# AI Mail Assistant

Gmail・Outlookのメールを自動取得し、AIで要約・分類してLINE通知やGoogleカレンダー登録を行うAIメールアシスタントです。

## Features

- Gmailメール取得
- Outlookメール取得
- OpenAIによるメール要約
- 重要度判定
- 予定メールの抽出
- Google Calendar自動登録
- LINE通知
- Supabaseへの処理ログ保存

## Tech Stack

- n8n
- OpenAI API
- Gmail API
- Microsoft Graph API
- LINE Messaging API
- Google Calendar API
- Supabase
